Superstore Sales Dashboard using Power BI
Project Overview
This project is an interactive Power BI dashboard developed using the Superstore dataset.
The dashboard analyzes:
Sales performance
Profit trends
Customer behavior
Product analysis
Regional analysis
Shipping performance
The project was designed using a modern dark dashboard theme with interactive slicers, KPI cards, and professional visual layouts.
